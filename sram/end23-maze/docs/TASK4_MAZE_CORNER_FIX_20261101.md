# 首次右拐墙面参考修复：END23 / ALG4 / MZ13

本轮按用户要求修复首次右拐卡住的问题，保留原功能。离线通过后仅加载SRAM，并使用用户本次已经明确给出的授权启动一次复测。不增加运行总时限或电机输出限制。

## 缺陷与证据

旧END22把相邻测距的允许变化设为“请求速度×时间＋噪声预算”。例如请求90 mm/s、测距周期100 ms、测距误差预算4 mm时，变化门槛约21 mm。这个请求速度没有经过实车速度标定；固定PWM使车辆实际推进更快时，正常接近同一面前墙也会多次进入阶跃确认，并增加参考代号。

路口对齐保存了旧参考代号。新距离被接受后，参考代号变化，对齐代码只会进入REFERENCE等待；等待恢复仍带着旧代号，因而再次等待，最后超时。首次停车的冻结前ToF代号为7，第二次为6；右侧均为1、左侧为0。两次均在参考等待后超时，底层IMU和通信健康诊断没有故障。旧日志没有冻结最初失配事务，因此不把推演当作完整实机逐帧回放。

100 ms异步采样的独立几何模型中，旧版在2.5倍及4倍简化速度比例下复现同样的ALIGN/WAIT反复及超时；修复版在同一输入与环境下通过前两个连续直角。这确认了代码中可重复造成该症状的缺陷，现场复测继续核对是否消除实机卡点。

## 修改范围

新增有效测距趋势：使用相邻两段真实测距变化及各自采集时间，判断运动轴上的同向连续推进，不把请求速度当实测速度。两段变化率相容时，更新同一墙面的距离，不制造换墙代号。单帧远/近尖峰、阶跃后的平台、横向开口以及反向突变仍走原来的独立多帧持续确认；无效帧撤销趋势历史，重复帧和过期采集时间不续有效期。

没有直接删除参考一致性检查，没有自动把新墙代号覆盖到旧锚点。真正参考不明时原处理保留。

独立模块源码为 `F:\FPGA\fw\maze_corner_fix\maze_tof.c` 和 `maze_tof.h`，候选保留冻结副本。重建入口 `tools/prepare_task4_maze_corner_fix.py` 的输出已与候选逐字核对。除导航核心、诊断和版本号外，其余固件保持原样；电机混合器与END22逐字一致。

新增只读 `maze ref`，记录行驶方向、参考方向、保存/当前代号、参考距离、边沿距离、对齐目标及待处理出口。它不修改状态或驱动许可。

连续短直角另有可重复的CROSS停死：当前右测距原始约600 mm、内缩60 mm，净距约540 mm；到同宽通道的175 mm居中点只能推进约365 mm，原固定跨越量却约517 mm。仅修复参考代号后，模型会一直停在CROSS。最终FIX2在发现下一真实开口、或前墙进入原有近墙观察区时，交给OBSERVE/ALIGN/DECIDE，而不是等不可能达到的固定进度；沿用原整车过线检查。离开节点时，节点原入口不再被重复登记为新开口。

额外短直角环境采用独立墙线段，保持600 mm通道、相邻竖直通道错开365 mm。参考修复初稿在两种优化下均复现CROSS停死；最终版本通过1/2.5/4倍比例的两个直角及整车过线。仅参考修复的初稿已归档在 `history/reference_only`，从未部署。
