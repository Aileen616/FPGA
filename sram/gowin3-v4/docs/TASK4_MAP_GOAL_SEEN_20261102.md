## 修改范围

独立候选 `build/soc/task4_map_goal_seen`，基于已冻结END24/MZ14，候选UART身份END25/ALG4/MZ15。原END24源码快照、FS和原上位机共147项摘要保持不变；当前板上仍是上次确认的END24，本轮未实时查询。

1. 建图模式通过原 `mt_input_t` 视觉字段接收后台结果，未新增公共接口或运动许可。后台零候选、未知、过期或多候选均不新触发GOAL；节点仍按原ToF出口选择探索。
2. 只有后台先看到新鲜有效的单个标志，才进入原停车/新token/多帧确认。旧token、旧图和重复帧仍不能登记终点。
3. 进入确认后，新鲜图像已经没有标志，直接撤销本次候选并继续探索；不再受静态coverage_verified=0阻塞这条恢复路径。阴性只表示撤销候选，不伪造“已完整观察整个视野”的结论。
4. 已看到候选后的确认窗口仍沿用原wait_ms（板级30秒），到期改为恢复探索，不报视觉等待MT_TIMEOUT。普通测距、参考、对齐等原有等待及故障处理保留，未添加车辆总时限或输出限幅。
5. 真实终点仍保留原几何位置核对和两帧确认；确认成功后登记节点，完整探索模式继续补齐分支，再返回已知终点停车。原驱动混合器、ToF测距和图像检测算法逐字保持。
