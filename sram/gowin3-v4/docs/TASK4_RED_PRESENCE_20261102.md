## 1. 最简设计

只判断完整有效图像中是否存在足够大的红色区域，不识别正方体、角度、黑柱或棕板。

RGB565各通道按原采图工具的向下取整方式展开到0～255，记为R/G/B。像素满足以下全部条件即为红色：

- R≥35且R≥G、R≥B。
- 令D=R−min(G,B)，要求255D≥70R。
- 要求5×abs(G−B)≤3D。

这些是连续HSV中亮度≥35、饱和度≥70/255、色相距纯红色≤36°的整数判据。没有浮点HSV变换；RGB565通道展开仍有常数整数除法。它与前期OpenCV量化HSV在舍入边界可能不同，不能宣称逐像素完全等价。

对二值红色图做8连通域遍历，任一连通域面积≥16像素即输出COUNT=1，否则COUNT=0。多个红色物体也输出1，诊断框保留面积最大的合格红域。没有宽高比、填充率、方形、转角、触边排除或腐蚀操作。分散噪点不会仅因全图总数量超过16而被合并成目标。

COUNT=1表示红色存在，不单凭它声称导航已经完成。原来的图像序号、时间、token和停车两帧确认接入保持；完整建图、返回终点、运动许可和故障逻辑也保持原样。

## 3. 接口和调用顺序

完整头文件见`fw/endpoint_red/endpoint_red.h`。

| 接口 | 用途 |
| --- | --- |
| `ep_red_pixel(pixel)` | RGB565单像素整数颜色判定 |
| `ep_reset()` | 取消旧计算，准备新完整帧 |
| `ep_pixel(index,pixel)` | 装载0～5999号像素，忙时/越界忽略 |
| `ep_begin()` | 完整帧启动；不完整帧报error=6，不能伪装阴性 |
| `ep_step()` | 分片执行直到完成/错误 |
| `ep_result()` | 只在done后读取非空静态结果 |
| `ep_workspace_bytes()` | 静态工作区字节数 |

调用顺序：reset→装载6000个不同下标→begin→主循环分片step→读取结果。原生产endpoint服务已按此顺序调用，不新增中断、外设寄存器控制或运动命令。

结果结构与原服务ABI一致。count只为0/1；error为0正常、5队列容量异常、6装载不完整。box的area是红色连通域面积，TH=70表示最低饱和度，K/SUPPORT为0，不再解释为原黑色算法的暗阈值/形态学支持。

## 5. 最简单的实机检验方案

目的仅为证明“新代码在当前摄像头真实画面中能区分有红/无红”，不测试导航或停车距离。

### 先决步骤：只在同一当前工程基础上生成SRAM候选

旧END25运行的仍是黑色检测器。电脑回放不能替代新红色代码在FPGA上的验证。因此实际板端验证需要：以本候选的新ROM重新综合/布局布线，确认时序与原引脚一致，生成对应完整FS，再仅加载一次SRAM。不能把旧END25的FS拿来充当红色候选，也不切换其他任务工程或写Flash。上板前实时确认现有身份、OWN/TRIAL和四轮输出；若断电回到Flash，必须先记录真实状态，不能沿用历史SRAM身份。

不需要重新标定IMU，不需要发车，不需要完整迷宫测试。首次用上一轮相同位置：距镜头约60cm、方块中心与镜头同高，不要求角度。

| 步骤 | 现场操作 | 只读检查与通过条件 |
| --- | --- | --- |
| 1 | 棕板上放红块 | 新候选END26/ALG5；两张不同新帧VALID1/ERROR0/COUNT1 |
| 2 | 只移走红块，保留棕板 | 两张不同新帧VALID1/ERROR0/COUNT0 |
| 3 | 原处放回红块 | 两张不同新帧VALID1/ERROR0/COUNT1 |

每次换物后先跳过第一张新发布帧，避免上一个摆位的在途帧残留，再读取后续两个不同SEQ；两帧间隔至少200ms。用`endpoint status`读取结果，必要时`endpoint box 0`核对框是否落在红块上。无需逐行导出图像，所以不会重复每张约一分钟的原图传输。

三步前后均读取`maze io`及`enc live 0..3`：OWN/TRIAL=0，四轮BUSY/ACTIVE/PWM/TARGET=0。不发START、不申请运动许可，也不调用需要IMU/ToF的maze goal探测作为本次红色存在验收。

三步通过即可判定“此摆位的静止红色终点检测可行”，随后再决定是否接入行驶确认。若失败，先保存有效新帧和框，不直接放宽到任意红点；仅处理本次失败原因，不增加角度采集矩阵。

局限：任何符合颜色及面积条件的其他红物体也会被视作红色存在。现方案适用于场地内终点红色物体有足够辨识度的前提，不具备区分红色胶带、红衣物与终点的语义能力。实际检测距离和移动停车尚未验收。
